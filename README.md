# personal_website

Source for [andreh0v.github.io/personal_website](https://andreh0v.github.io/personal_website/) —
portfolio, academics, experience and code projects.

The static site lives in `docs/` (vanilla HTML/CSS/JS + Chart.js). Portfolio figures in
`docs/data/` are published as percentages only and are refreshed automatically on weekdays
by a build pipeline in a separate private repository.
